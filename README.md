UE UI plugin (Look in Tools Tab) for finding and repairing Blueprint assets affected by broken or outdated <b>user-defined</b> struct references.
Helps with common Unreal Blueprint issues such as: structs --> invalid struct pins, stale DataTable row structs, bp nodes that need to be refreshed after struct changes.
What it does:
Finds Blueprint assets by name or /Game/... path.
Runs "Refresh All Nodes" on the selected Blueprint without manual log untangling/asset opening
Compiles after refreshing nodes.
Shows if asset has unsaved changes.
Lists user-defined structs used by the selected Blueprint.
Shows where each struct asset is located.
Parses build/cook/package logs to do it easily.
Extracts from log assets with struct errors.
